# DIG — 画面の言葉（デザイン言語）

更新日: 2026-10-09

DIG（検索で `dig` と打つと開くカードのローグライク）の画面を作るときの約束。
対象は `src/features/dig/dig.css` と `src/features/dig/ui/` 以下。
プレイヤー向けの説明は `src/content/blog/dig-wiki.mdx`。この文書は開発向け。

ここに書いたことだけを使う。新しい色・線・動き・触れ方が要るときは、先にこの文書を直す。
この文書と食い違う実装は、解釈の違いではなく不具合として扱う。

---

## 1. 原則

1. **塔が本体。** 画面の主役は、斜めに見下ろしたフロアの積み重ね（`ui/tower.ts`）。
   脇の欄と手札は、塔で起きていることを読むための添え物。
2. **数は札の上で言う。** 「いま使ったら何がいくつ動くか」は、札の面と相手の棒に出す。
   説明文で繰り返さない。
3. **一つのことは一か所で。** 同じ情報を二か所に出さない。出すなら片方を薄くする。
4. **状態は形と色で。** 動きは状態が変わったことを示すときだけ。動きを消しても読める。
5. **押す前に分かる。** 押したら何が起きるかを、押す前に見せる（ホバー・一度目のタップ）。

---

## 2. 色

紙（`--bg`）と墨（`--ink`）が地。色は意味を持つものにだけ、まばらに置く。

| 役割       | トークン                                       | 使う場所                                                                                                                                                          | 使わない場所                                |
| ---------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| 墨         | `--ink`                                        | 本文、確かなもの、決まった数                                                                                                                                      | —                                           |
| 中墨       | `--ink-2`                                      | 札の縁（ふだん）、補足の本文                                                                                                                                      | 見出し                                      |
| 薄墨       | `--ink-3`                                      | 添え書き、まだ選べないもの、鍵（キー）、ラベル                                                                                                                    | 押せるものの字                              |
| 琥珀       | `--amber-text`（塗りは `--amber`）             | **あなた・押せるもの・広い面での強調**。選んだ道、決めた一手、進む釦、構えた札、道に効く箱                                                                        | 危険の印（危険は墨の太字＋`▲`）、悪い知らせ |
| 緑         | `--dig-green`                                  | **小さく済む良い知らせ**。回復の数（`.dig-heal`）、回復した棒（`.dig-meter.is-healed`）、ミニゲームの成功（`.dig-gauge.is-ok`）、札片の回復（`.dig-out.is-heal`） | 文全体、広い面、見出し                      |
| 青         | `--dig-blue`                                   | **いま向き合える相手と、いま効いているもの**。相手の記号・計器・信頼の糸・手がかり（`.dig-out.is-blue`）                                                          | 自分の情報                                  |
| 金・銀・銅 | `--dig-gold` / `--dig-silver` / `--dig-bronze` | エピテットの格（`.is-gold` ほか）だけ                                                                                                                             | 格以外の強調                                |

- 琥珀は「広い面を使いたいとき」、緑は「小さな範囲で済むとき」。迷ったら琥珀を減らす。
- 悪いことは色ではなく、墨・薄墨と言葉で言う（`倒れる見込み 30%` は墨、`歯が立たない` は `.dig-warn`）。
- 同じ画面に琥珀の面は一つ（選んだ道の枠か、構えた札か、進む釦）。二つ目は線か字に落とす。

---

## 3. 線

- 線は **1px**（`--dig-line` = `1px solid var(--rule)`）。
- **2px は「決めたもの」だけ**: 選んだ選択肢（`.is-chosen`）、進む釦（`.dig-go`）。
- **実線**は確かなもの。**点線・破線**はまだ起きていないもの・見込み・自分に返る効果
  （回数が尽きた札 `.is-spent`、自分に掛かる札片 `.dig-out.is-you`、何も押していないときの詳細欄 `.dig-armdetail.is-idle`）。
- 二重線（`box-shadow: inset 0 0 0 1px`）は「いま構えている」札だけ（`.dig-card.is-armed`）。
- 影は「押せる札が浮いている」ことを示す下端の 2〜3px だけ。ぼかした影は使わない。

---

## 4. 字

- **等幅**（`--font-mono`）: 数、ラベル、鍵、時刻、上帯、相手の棒の数値。
- **普通の字**（`--font-sans`）: 文、札の名、台詞。
- 大きさはトークンで（`.dig` に定義）:

| トークン       | 大きさ | 用途                                     |
| -------------- | ------ | ---------------------------------------- |
| `--dig-t-xs`   | 10px   | 鍵、細かいラベル、「もう一度押すと切る」 |
| `--dig-t-sm`   | 11px   | 添え書き、説明枠の二行目以降             |
| `--dig-t-md`   | 12px   | 札の効き目の文、説明枠の本文             |
| `--dig-t-base` | 13px   | 札の名、釦、欄の本文                     |

- 見出しは太さで作る（大きさを足さない）。場面の一語（`.dig-scene__word`）だけが例外。
- 行間は文 1.55〜1.6、札の名など短いもの 1.3。

---

## 5. 間

`--dig-s-1` 4px、`--dig-s-2` 8px、`--dig-s-3` 12px、`--dig-s-4` 16px、`--dig-s-5` 24px。

- 同じ塊の中は 4〜8px、塊と塊は 12〜16px、欄の区切りは 24px。
- スマホの左右の余白は 12px（手札の枠）〜16px（欄）。

---

## 6. 動き

- 状態が変わったことを示すときだけ動かす（札が配られる、手番が落ちる、浮く、消える）。
- 短く: 触れたときの色の移り変わりは `--dig-fast`（0.12s）。
- 位置の移動は FLIP（その場での箱の並び替え）か `translate` の数 px まで。
- `prefers-reduced-motion: reduce` では、浮き・跳ね・明滅・並び替えのすべり・押したときの沈みを消す。
  そのときも、印（線・色・薄さ）だけで状態が読めること。

## 7. 触れ方

| 状態               | 見え方                                                         | 条件                                                                 |
| ------------------ | -------------------------------------------------------------- | -------------------------------------------------------------------- |
| ホバー             | 縁が琥珀。押せる札は下端の影も琥珀                             | `@media (hover: hover)` の中だけ。指の端末で押した色が残らないように |
| 選ぶ（キーボード） | ホバーと同じ見え方に、琥珀の 1px の輪（`outline-offset: 2px`） | `:focus-visible`                                                     |
| 押す               | 1px 沈む（`translate: 0 1px`）                                 | `:active`。動きを減らす設定では沈まない                              |
| 押せない           | 薄く（`--dig-off` = 0.45、札は 0.38）。触れても変わらない      | `:disabled` / `.is-off`                                              |
| 選んだ             | 2px の琥珀の縁                                                 | `.is-chosen` / `aria-pressed="true"`                                 |

### 説明（ツールチップ）

- ブラウザの `title` は表示に使わない。`ui/hovertip.ts` の共通の説明枠（`.dig-tip--hover`）が、
  触れたときに `title` を預かって（`data-tip`）出す。読み上げには `aria-description` で残す。
- 出る: マウス・ペンで触れて 0.42 秒（一度出たら、隣へ移るときは待たない）。キーボードで選んだとき。
- 出ない: 指の端末、押した瞬間、巻き取ったとき。描き直しで触れていた要素が消えたら畳む。
- 一行目が本文（墨）、二行目からは添え書き（薄墨）。`title` は改行（`\n`）で行を分けて書く。
- 下に出し、入らなければ上に。左右は画面の端から 8px 以内に収める。
- **見えている文を繰り返すだけの `title` は付けない。** 内部の分類名（「勝つ道」「低連鎖・高安定」のような道のラベル）も出さない。
- 地図の部屋の説明は別の枠（`.dig-tip`、`showTip`）だが、見え方は同じ。

### スマホの札（二度押し）

- 一度目: 構える（`.is-armed`）。二重線で 6px 浮き、ほかの札は 0.5 に引く。
  上の相手の棒に動く分が映り、手札の下に詳細欄（`.dig-armdetail`）が開く。
- 二度目: 切る。
- 何も構えていないときは、詳細欄の場所に点線の枠で操作の一行だけを出す（空白を残さない）。

## 8. 改行

- `.dig` 全体で `word-break: auto-phrase`（文節で折る）、`line-break: strict`、`overflow-wrap: anywhere`。
  `auto-phrase` はダイアログの `lang="ja"` で効く。英語では通常の折り返し。
- 文（`p` / `li` / `dd`）は `text-wrap: pretty`。見出し・釦・札の名は `text-wrap: balance`。
- 『』《》［］〈〉の括りは割らない（文節の折り返しに任せる。足りなければ括りごと `white-space: nowrap` の span に）。
- **省略（…）はしない。** 長いものは二行までにして（`-webkit-line-clamp: 2`）、それでも長ければ畳む。
  - 札の名（`.dig-card__name`）、案内の帯の「裏で効いたもの」（`.dig-why-chip`）は二行まで。
  - 例外は上帯の場所の名前だけ（スマホで一行に収める帯なので、`.dig-where` は省略する）。
- 等幅の数（`26/28`、`+3`）や、ラベル＋数の組は割らない（`white-space: nowrap`）。

## 9. 配置

### 広い画面

```
┌ 上帯（場所・時刻・体力・精神・金・硬度）──────────────┐
│ 塔（見取り図）                 │ 脇の欄（道の読み・その場で・目標・状況・ヒント） │
│   地図/手札の切替・拡大縮小    │                                               │
├ 手札（5 枠）・エピテット ─────────────────────────────┤
```

### 狭い画面（`max-width: 52rem`）

`.dig-app` の格子: `'bar' 'foe' 'view' 'panes' 'tray' 'side' 'step'`。

- **地図はいつも残す。** その下を「札」と「情報」（遭遇中は「札」と「相手」）の切り替えで使う。
  切り替え（`.dig-panes`）は消さない。
- 遭遇中は、自分の棒のすぐ下に相手の棒（`.dig-foebar`: 名前・硬度・次の手、倒す／折る／打ち解ける／暴く）。
  地図は画面の約 3 分の 1（`--dig-view-h`）で、カメラは足元から下の階が見える位置。
- 決着のあとは切り替えを隠し、下端の「前へ／次へ」（`.dig-stepnav`）で
  結末 → 拾う一枚 → 手放す一枚（手持ちがいっぱいのとき）→ 受け取る、と一段ずつ進む。
  段の真ん中は点だけ。何をする段かは、欄の中の手順の一文と下端の釦が言う（同じことを二か所で言わない）。

### 受け取り（決着のあと）

- **指示は一か所。** 何をするかは手順の一文（`.dig-confirm__step`、番号つき）だけが言う。
  候補の列や見出しに「手放す一枚を押す」のような同じ指示を重ねない。
- **選んだ印は一つの形。** 拾う一枚も手放す一枚も、札の頭（名前と回数のあいだ）に小さな枠の印
  （`.dig-card__mark`）。本文には重ねない。狭い札では印と回数が名前の下の行へ回り、名前は削らない。
- **地図のとき（広い画面）**、地図の欄は二段になる：地図が縮み、その下の帯（`.dig-band`）に拾える札が
  一段で並ぶ（四枚まで）。右の欄は 決着 → 余韻 → 受け取り（`.dig-claim`：手順の一文 → 手放す一枚 → 釦）。
  手放す一枚は「その場で」の箱と同じ形の一列（名前・回数、二行目に効き目）。拾うのは左、決めるのは右。
  下の帯が右の欄の下に食い込まないので、右の欄は全高のまま。
- **狭い画面**は下端の帯に 拾える札 → 手放す一枚（下の段）→ 手順の一文、送りは下端の「前へ・次へ」。
  指の端末には触れたときの説明が出ないので、札を押すと中身（効き目・眠りぎわ・刻まれた語・一文）が
  札の列の下に開く（遭遇の `.dig-armdetail` と同じ形）。何も選んでいないときは出さない。
  受け取りのあいだは「地図／手札」の切り替えを出さない（帯に全部揃っている）。
- 狭い画面で手札の一覧を開くと、地図の枠ではなく上帯の下を全部使い、札は二列で縦に並ぶ。
- **手札のとき**、上から 拾える札 → 手持ちの札 → 持ち物 → 手順の一文（拾える札と手持ちを隣り合わせで
  見比べる）。持ち物がいっぱいで拾えない道具があるときだけ、持ち物は拾える札のすぐ下へ上がる
  （地図のときも、その場合だけ帯に持ち物の行が出る）。整えるの手札は 手持ちの札 → 持ち物 → 記憶。
- **エピテットは枠で囲わない。** 《》がもう語を括っているので、手元のエピテット（`.dig-pill--ep`）も
  格の色の字だけで並べる。触れると琥珀、選んでいるあいだは琥珀の下線。
- **エピテットの操作は札の中。** 刻まれたエピテットは札の本文の下に、語・効き目・「剥がす」釦の欄
  （`.dig-deck__eps`）。整えると受け取りで同じ形。札の外に別の「剥がす」一覧を作らない。
  中に釦がある札は `div` を押せる形にする（`pressable()`。Enter と Space は札そのものに触れているときだけ）。

### 札のレベルと身につける品（覚えることを減らす）

- **札が覚えるのは二つだけ：レベル（Ⅰ〜Ⅲ）とエピテット。** 構成・主役の札・原型の重ねがけ・暴走のような
  「札の外で成り立つ名前」は作らない。強さの理由は、いつも札そのものの上に見える。
- **レベルは同じ札を重ねて上げる。** 持っている札をもう一度拾う・買うと重なる（枚数は増えない）。
  札の頭の名前の脇に `Ⅱ`・`Ⅲ`（`.dig-lv`）。拾える札には「重ねるとⅡ」「Ⅲ（これ以上は重ならない）」の一言だけ。
- **持ち物は二種類。** 使うと減る品（休む・備える・探る）と、減らない **身につける品**。身につける品も
  持ち物の枠を一つ使う。押して使うものではないので枠で囲わず、名前だけ。外す操作は平時に置かない：
  持ち物がいっぱいで道具や身につける品を拾うときに、受け取りの持ち物の列で「置いていく」一つを押す（同じ箱を押すたびに一段ずつ：取り消し線 → 灰色 → 縮みながら落ちて消える。動きは段が変わった直後の一度だけ。灰色までは仮で、釦のない所や別の品を押すと外れる。消えたら決まり）
  （手放す一枚と同じ形の一列）。拾う・買う札の頭には回数ではなく「身につける」。
  古物商では、持ち物がいっぱいでも品は押せる（値段に「・一つと入れ替え」）。押すと手放す一つの一列が開き、
  札の入れ替えと同じく、選ぶまでは何も減らない。
- **効く先のない品は押せない。** 体も心も満ちていて、合う札もどれも満ちているなら、品の箱は灰色で、
  題に「いまは効かない：…」。効いたときは、戻した札を「『名』の回数 1/2 → 2/2」と名指す（古物商の手帳と同じ形）。
- **確かな効き目と、試みを言い分ける。** 確率で外れる手がかりは「探る」（外れると相手が「……さあね。」）。
  見透かしの余韻も、予告が本当の姿で見えるのは確かで、手がかりは遭遇の初めに一つ「探る」。
- **内部の名を出さない。** 記憶を得る効き目は「記憶《怖れ》を得る」と名で書き、説明の最後に記憶の文を添える。
- 部屋の札（地図のホバー）は、地図から外れたとき・何かを送ったときに閉じる。過ぎた階や、今はできない行動を案内しない。
- **条件の文には、いまの値を一つの括弧で添える**（`.dig-live`）。並びは「（いま 3 手番目、23:00、体力 26/28）」：
  場面（手番・時刻）→ 体の値 → 相手の様子。
- 身につける品は、ほかの仕組みと同じ口を使わない（能力値の足し算は記憶、決着ごとの倍率は肩書きと余韻、
  回復と回数の補充は品）。一撃の上限、判定の振り直し、溢れた回復の汲み置き、レベル・刻んだ数・手番・
  持ち物の空き・時刻を数えるもの、のように、その品にしかない手触りにする。

## 10. 部品の言葉

| 部品   | クラス       | 意味                                                                                                                                          |
| ------ | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 札     | `.dig-card`  | 手札の一枚。`is-live` 押せる、`is-off` 押せない、`is-lean` 道で頼る／連鎖になる、`is-armed` 構えた、`is-spent` 尽きた、`is-open` 押して開いた |
| 札片   | `.dig-out`   | いま使ったら動く数。`is-end` 決着、`is-blue` 相手の信頼・手がかり、`is-you` 自分に掛かる、`is-heal` 回復、`is-cost` 代償                      |
| 棒     | `.dig-meter` | 体力・意志・信頼・手がかり。減る分は斜線、増える分は薄い塗り                                                                                  |
| 道の札 | `.dig-chip`  | 道の読みの選択肢（安定・高連鎖）と、推奨を切る「自分の脚で」                                                                                  |
| 枠     | `.dig-plan`  | 行き先を決めると開く琥珀の枠。中身 → その場で → 進む釦                                                                                        |
| 箱     | `.dig-spot`  | その場でできること。休む → 備える → 探る の順。道に効く箱は `is-fit`                                                                          |
| 帯     | `.dig-guide` | 案内の帯。名場面・いまの一文・裏で効いたもの・ヒントを一つずつ                                                                                |
| 説明枠 | `.dig-tip`   | 触れたときの説明（7 章）                                                                                                                      |

## 11. 言葉づかい

- 一つのものは一つの呼び名で: 札（カード）、相手、部屋、下りる、その場で、道の読み、刻む、剥がす、構える、切る。
- 動詞で終える釦（「受け取る」「拾わずに進む」）。名詞だけの釦は切り替えとタブに限る（「札」「相手」）。
- 数は等幅で、符号は `+3` / `−2`（全角マイナス）。
- 英語は画面に出る直前に置き換える（`src/features/dig/i18n/`）。新しい文言を足したら `i18n/en/ui.json` にも足す。
