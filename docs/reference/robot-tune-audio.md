## 切り出し基準と未検証事項

基準は冒頭 0〜3 秒のフレーズと、その後に音が重なった同じフレーズ。
短いアタック間隔だけでなく、周波数帯別の包絡の並びを冒頭と後半で照合した。
パターンの反復候補は約 2.8911041666666666 秒（138,773 フレーム）で、
その 2 回分に相当する波形の再帰間隔は約 5.782208333333333 秒だった。
継ぎ目のサンプル値と傾きを合わせるため、入口を数 ms の範囲で探し、
終点を再帰間隔から 12 フレーム（0.25 ms）短く微調整した。

これは信号の相関から得た候補であり、拍数や音楽上のフレーズ区分の確定値ではない。
切り出し区間内の休みはすべて反復時間に含まれる。休みを別に追加した処理はない。
ただし、ユーザーが指摘した**末尾の 0.5 拍休み**を独立に特定できていないため、
「発音する本体 → 末尾 0.5 拍休み → 同じフレーズの頭」の接続が成立するかは未検証。
発音部分の長さと休符を分けて確認し、戻りで休みが延びたり重複したりしないかを調べる。
PCM の一致とフレーム数は確認済みだが、聴感で自然なループであるとは確定していない。

以前 push した 13.089479166666667〜17.248125 秒の切り出し（約 4.159 秒）は、
ユーザーの試聴で戻りのリズムが跳ぶと指摘されたため撤回し、今回の WAV で置き換えた。
続く約 4.336 秒の確認版も、冒頭のフレーズ全体との対応を確認せず周期だけ合わせた候補で、
現在の WAV には使っていない。

## 追従の結果

`node ./scripts/robot-tune/bake.ts` が MP3 と `envelope.ts` を作り直し、拍も音から測る。

| 量                                  | 値                            | 測り方                                                                                                                          |
| ----------------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 8 分音符 `EIGHTH_SEC`               | 0.180686 s（約 166 BPM）      | 低域＋高域の RMS の対数の増分（5 ms 刻み）を、ループ 4 周ぶんの自己相関で探し（0.15〜0.22 s）、ループ長をその整数倍に丸めて割る |
| ループ `LOOP_EIGHTHS`               | 32（16 拍）                   | ループ長 / 周期 = 32.02                                                                                                         |
| イントロ `INTRO_EIGHTHS`            | 64（32 拍）                   | 最初の立ち上がり（0.45 s）からループ頭まで                                                                                      |
| ループの格子の位相 `LOOP_ONSET_SEC` | 0 s                           | イントロの格子をそのまま延ばした位置（ループ頭は休みで始まるので、ループの最初の音では測らない）                                |
| `LOOP_ACCENTS`                      | 8 分音符ごとの立ち上がり 0..1 | 各 8 分音符の 10 ms 前〜45 ms 後の最大値                                                                                        |

無音区間（`LOOP_SILENCES`）を 8 分音符で数えると、ループは
(0.86–1.99) (4.95–5.98) (7.06–7.97) | (16.82–17.99) (20.95–22.0) (23.11–23.99)。
8 拍のフレーズが 2 回で、どちらも 1・5・7 番目の 8 分音符の後ろ半分が休み、
休みの終わりは格子に揃う。イントロも同じフレーズが 4 回（休みは 1・5・7 番目、
後半のフレーズでは一部が鳴る）。末尾の休みはループの頭（0.86–1.99）にあり、
休みの延びや重複は格子の上では見られない。聴感での確認は未了。

振付（`choreo.ts`）はこの値から組む。ループ前半で 2³ の殻 7 個、後半で 3³ の殻
19 個を積み、各半分で `LOOP_ACCENTS` が `HIT`（0.5）以上の 8 分音符をすべて
着地点にして殻を均等に分ける。現行の音源では前半 2・6・8・11、後半 18・19・20・
22・24・27・29。カメラは後半でいちばん強い 8 分音符（18）に向かって回り込む。ループでは
休みで絵を止めない（面だけが消えて線画になる）。止めるのはイントロだけ。テストは「強い立ち上がり
すべてに着地があること」「着地がすべて強い立ち上がりの上にあること」を見ていて、
テンポや拍数を決め打ちしていない。

## 音源を差し替えたとき

1. `node ./scripts/robot-tune/bake.ts`（`libmp3lame` が使える `ffmpeg` が必要）。
2. 着地点は `LOOP_ACCENTS` から自動で決まる。`pnpm test:unit` が外れを知らせる。
3. ブラウザでイントロからの接続と複数周の再生、休みと動きの同期を確認する。
