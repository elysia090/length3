# DIG コードの地図

更新日: 2026-10-09

DIG（`src/features/dig/`）のどこに何があるか。画面の言葉（色・線・字・触れ方）は
[dig-design-language.md](../specs/dig-design-language.md)、遊び方は `src/content/blog/dig-wiki.mdx`。

## 層

```
core/     世界の形・イベント・畳み込み・規則・乱数（遊びの土台。画面を知らない）
content/  中身のデータ（札・人・エピテット・記憶・出来事・階・台詞）
sim/      遊びの進め方（決定 → イベント）、道の読み、試しの遊び手
ui/       画面（DOM と塔の絵）。sim と content を読むが、書き換えは send でだけ
css/      画面の見た目（主題ごと。dig.css が順に読み込む）
i18n/     英語（画面に出る直前に置き換える）
```

遊びはすべて、一つの種と操作の列から積み直す（`sim/game.ts`）。保存は操作の列で、
`content/balance.ts` の `DATA_VERSION` が変われば古い保存は読まない。

## ui/

| ファイル                                                             | 中身                                                                                                     |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `app.ts`                                                             | 画面の持ち物（状態）と描き直し、操作の送り出し、イベントへの反応（演出）、遭遇・地図・手札・人物作成の欄 |
| `ui.ts`                                                              | 外へ出した欄が app に頼む窓口（`send`・`render`・`caption`）                                             |
| `places.ts`                                                          | 食堂・古物商（入れ替えで買う）・出来事と結果、持ち物の列、剥がして残す列                                 |
| `route.ts`                                                           | 道の読みの中身の表、その場での箱の並び（隠し順序・道に効くか）、付け替えと刻む先                         |
| `cards.ts`                                                           | 札の顔（効き目の印・エピテットの名札・拾い物・いま使ったら動く数・拾える札と品の箱）                     |
| `parts.ts`                                                           | 状態を持たない小さな部品（欄の見出し・選ぶ箱・数え上げ・計器・部屋の中身・状況）                         |
| `words.ts`                                                           | 呼び名と数え方（部屋・素手・時刻・階・台詞の選び方・行き方）                                             |
| `tower.ts`                                                           | 塔の見取り図（カメラ・床・人・場面）。`pixel/` は場面の描き方                                            |
| `hovertip.ts`                                                        | 触れたときの説明（title の代わり）                                                                       |
| `preview.ts`                                                         | いま使ったら何が動くか（世界の写しで試す）                                                               |
| `hints.ts`・`badges.ts`・`sound.ts`・`save.ts`・`dom.ts`・`state.ts` | ヒント、効き目の印、音、保存、DOM の作り方、手番の行の型                                                 |

## css/

`dig.css` が下の順に読み込む。後のファイルほど強い（同じ強さの規則なら後が勝つ）。

| 順  | ファイル     | 中身                                             |
| --- | ------------ | ------------------------------------------------ |
| 1   | `base.css`   | トークン、ダイアログ、釦の触れ方、文の折り返し   |
| 2   | `bar.css`    | 上帯                                             |
| 3   | `board.css`  | 塔の欄、寄る・見渡す、切り替え                   |
| 4   | `side.css`   | 脇の欄、目標、状況、場所と部屋                   |
| 5   | `guide.css`  | 案内の帯                                         |
| 6   | `hand.css`   | 札、手札の帯、持ち物、手札の一覧                 |
| 7   | `enc.css`    | 向き合う（一巡・四つの道・相手の段）             |
| 8   | `create.css` | 人物を決める                                     |
| 9   | `state.css`  | 部品をまたぐ状態の印（格の色・拾い物・跳ね）     |
| 10  | `reward.css` | 受け取り、食堂・古物商・出来事、終幕、前へ・次へ |
| 11  | `plan.css`   | 道の読みとその場で                               |
| 12  | `util.css`   | 色の名札（quiet・amber・blue・heal・label）      |

規則を主題ごとに分けたとき、同じ要素に同じ強さで効く規則どうしの前後は元のまま残した。
主題の外に置いた規則には「並びの都合でここに置く」と注釈がある（どの規則より後に効く必要があるか）。
分けた前後で、主要 14 画面の全要素の計算済みスタイルが一致することを確かめてある。

## 支配項（2026-10-09 の棚卸し）

| 種類   | 支配項                                                                 | 手当て                                                                                                                      |
| ------ | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 実行時 | 塔の描き替え（三角形の塗り・点の書き出し・額縁・寸法の読み取り）       | 塗りは行ごとに範囲を絞る（同じ点を塗る試験つき）、額縁は一度だけ数える、寸法は ResizeObserver、止まっているあいだは 30 こま |
| 実行時 | 道の読み（`sim/advise.ts`）                                            | 平均 30ms・最悪 115ms（地図に着いたときだけ）                                                                               |
| 試算   | 道どおりに遊ぶ試しの遊び手が、エピテットを剥がしては戻す輪に入っていた | 値踏みを剥がしたあとの盤で測り直し、移すのは一倍半を超えるときだけ、剥がす・刻むを一組に                                    |
| 大きさ | `ui/app.ts`（5,100 行の一つの閉包）                                    | 状態を読まない部品と場所の欄を外へ（4,000 行）。残りは状態と演出に結びついた欄                                              |
| 大きさ | `dig.css`（4,300 行、継ぎ足しの順）                                    | 主題ごとの 12 ファイルへ                                                                                                    |

次に外へ出すなら、状態への依存が少ない順に：道の読みの欄（`mapPanel`・`plan`・`spotRows`）、受け取り（`rewardPanel`・`rewardDeck`）。
いちばん絡み合っているのは `react`（イベントへの反応。38 の状態に触れる）で、演出の時刻を一つの物にまとめてから分けるのがよい。
