# Getting Started

Welcome to **length3**, a technical blog built on Astro 6 with TypeScript in strict mode,
MDX content collections, and Cloudflare Workers deployment.

## Technology Stack

This blog uses:

- [Astro 6](https://astro.build) — the web framework for content-driven websites
- **MDX** — Markdown with JSX component support
- **Content Layer API** — type-safe content collections
- **Cloudflare Workers** — edge-native deployment

## A Section with Code

```typescript
const greeting = 'hello, length3';
console.log(greeting);
```

## Japanese Typography

This blog has full support for Japanese text including `<ruby>` annotations,
`line-break: strict`, and `text-wrap: pretty` for well-composed CJK paragraphs.

例えば、<RubyText base="東京" reading="とうきょう" />は日本の首都です。
