**Length³** is a technical blog engineered as a portfolio piece: every architectural decision is deliberate, every dependency earns its place, and the reading experience is treated as a first-class concern.

## Stack at a Glance

| Layer     | Technology                                   |
| --------- | -------------------------------------------- |
| Framework | Astro 6 (static output + Cloudflare adapter) |
| Content   | MDX + Content Layer API (Zod-validated)      |
| Runtime   | Cloudflare Workers (edge-native)             |

The blog is statically generated at build time and served from Cloudflare's edge network — no origin server, no cold starts.

## Content

Articles live in `src/content/blog/` as `.md` or `.mdx` files.
Frontmatter is validated with a Zod schema: `publishDate` is coerced to a native `Date`, `draft: true` hides a post from all listings, and `lang` switches date formatting and the document `lang` attribute between `en` and `ja`.

MDX lets you embed Astro components directly in prose.
The `RubyText` component, for example, renders a proper `<ruby>` element — <RubyText base="東京" reading="とうきょう" />は日本の首都です。

## Features

- **Table of Contents** — extracted from the MDX heading tree, sticky on desktop, with IntersectionObserver-driven active-section highlighting
- **Reading time** — CJK-aware: characters counted at 400 chars/min, Latin words at 200 words/min
- **Tag archive** — Unicode-safe slug canonicalization; CJK tags survive the transform intact
- **Full-text search** — Pagefind with a custom `segmented-pagefind` integration that uses `Intl.Segmenter` to insert word boundaries before indexing Japanese text
- **Japanese typography** — `<ruby>` annotations, `line-break: strict`, `font-feature-settings: 'palt'`, `text-autospace: ideograph-alpha`

## Deployment

`pnpm build` produces a static `dist/` that is deployed directly as a Cloudflare Worker:

```sh
pnpm build
pnpm exec wrangler deploy --config dist/server/wrangler.json
```

CI (GitHub Actions) runs lint → build → Playwright E2E on every push.
Production deploys are manual via `workflow_dispatch` — deliberate, decoupled from CI merges.

## Design Principles

**Reading-first.** Two weights of two typefaces, one amber accent colour, 680 px prose measure, empty right column on article pages.
Hierarchy comes from spacing and type, not decoration.
