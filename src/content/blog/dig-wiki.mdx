一回の挑戦はおよそ四十分。三つの区画の底を抜ければ、ひとまず終わり。その先は、構成が持つ限り下りられる。

## 始める

最初の画面で、職と名前を決める。職ごとに、初めの札と能力値と癖が違う。

| 職 | 一言 |
| --- | --- |
| 夜警 | 遭遇の初めに守り 3。深夜は［夜］の札が強く、残った守りが信頼にこぼれる |
| 測量士 | ［場所］［視線］の札がよく効く |
| 映写技師 | 連鎖が深く効く（連鎖 +2） |
| 記者 | 手がかりを見るたびに金 3。［公開情報］の札がよく効く |
| 錠前師 | 立ち去る +20%。［私的情報］の札がよく効く |
| 看護師 | 回復が 1.5 倍。弱った相手が心を開きやすい |
| 溶接工 | ［技術］［身体］の札がよく効き、毎手番 守りと構えが +1 |

能力値は六つ。体格・腕力・防御・胆力・洞察・敏捷。体格が体力の、胆力が精神の上限を決める。

## 画面

- 上の帯：いまの階（B いくつ・その階の用途）、時刻、体力、精神、金、硬度。
- 左：建物の断面。灯りを提げた琥珀の人影があなた。隣の部屋や下の階へは、点線の道でつながっている。
- 右：いまやることの欄。地図の上では「道の読み」「その場で」「目標」、向き合っているあいだは相手の欄に変わる。
- 下：手札（五枠）と、エピテット、記憶、構成。

右下の ＋ − で、近くと遠くを切り替える。ホイールでも同じ。

硬度は総合の強さで、1 の滑石から 10 の金剛石まで。相手の名前の横にも出る。数字が墨の枠で囲まれていたら、正面からは歯が立たない相手だ。

## 下りる

地図の上では、点線でつながった部屋を押すと進む。部屋には、人、危険、出来事、食堂、古物商、そして区画の最後の相手がいる。

「道の読み」は、先の道を試しに通してみた結果を三つ出す。

- 安定：最後の相手の前に、体力がどれだけ残るか。
- 高連鎖：構成の噛み合いが多い道。崩れたときの損も大きい。
- あと一つ：成立しかけているビルドの、足りない一つが拾えそうな道。

時間に締め切りはない。夜は明けて、また夜になる。深夜のあいだだけ効く札や記憶がある。

## 向き合う

人と同じ部屋に入ると、向き合う。相手は次の手を先に見せる（たまに嘘をつく）。

決着の道は四つある。どれか一つを尽くせば終わる。

| 道 | 減らす・満たすもの | 主に効く札 |
| --- | --- | --- |
| 倒す | 相手の体力を 0 に | 削る札 |
| 折る | 相手の意志を 0 に | 脅す、揺さぶる札 |
| 打ち解ける | 信頼を相手の求める数まで | 話す、寄せる札 |
| 暴く | 手がかりをすべて見る | 見る、探る札 |

手番ごとに、札を一枚使うか、素手で動く。札は数字キー 1〜5、素手は Q（押す）・W（構える）・E（話す）・R（立ち去る）。相手の手が強そうなら、構えて受ける。

向き合っているあいだ、札には「いま使ったら何がいくつ動くか」が出ている。倒せる、折れる、と出ている札は、それで決着がつく。

## 点

札の数字には、その場の条件の点が足される。掛け算ではなく足し算なので、札の数字に足せば暗算できる。

| 条件 | 点 |
| --- | --- |
| 連鎖（直前の札とタグが重なる） | 一つ目 +2、二つ目 +4、三つ目から +6 |
| 見せ場（その部屋で輝くタグ） | +3 |
| 相手の弱いタグ | +3 |
| 相手の守るタグ | −3 |
| 原型が相手の原型に答える | +3 |
| 書き留めておいた | +4（一度だけ） |

連鎖が決まると、あなたが一歩踏み込み、輪が広がる。続けた数だけ輪が増え、頭の上の四角が数を数える。

共鳴は、決着のときにまとめて受け取るもの。札、記憶、構成、エピテットが働くたびに灯りが一つ点く。二つで金、三つで札の回数、四つでエピテット、六つで体と心が戻る。

## 構成

- エピテット：《夜の》《重い》のような語。札に刻むと札の効き方が変わる。同じ語が、人や場所に付いていることもある。地図の上で語を押し、白く浮いた札を押す（札へ落としてもいい）。
- 記憶：決着で持ち帰るもの。能力値やタグを足すものも、重荷になるものもある。悪い記憶には点線の下線が引いてある。
- 構成（ビルド）：タグと原型がそろうと成立する。主役の札の章や原型の重なりで、暴走、極みと段が上がる。

主役の札は二十枚ある。使い込むと章が進み、三章で話が閉じる。

## 区画と掟

区画ごとに、手番の回し方が少しずつ変わる。上の区画の掟は、下でも生きている。

| 区画 | 掟 | 変わること |
| --- | --- | --- |
| 夜の街 | なし | 四つの道と連鎖を覚える |
| 記録の階 | 読まれる | 同じ札を続けて使うと、二度目から −3 |
| 琥珀の階 | 固まる | 守りと構えが手番をまたいで残る。受ける一撃は +1 |

区画の最後の相手の扉の前で、一度だけ息を整える。体と心が六割までは戻る。

最後の相手からは退いてもいい。相手は傷を覚えていて、あとで再戦できる。

## 目標

右の欄に、いつも大・中・小の目標が三つある。大きさは四角の大きさで見分ける。届くと見返りがあり、次の目標が入る。届かずに挑戦が終わっても、進んだぶんは次の挑戦に持ち越す。

## 拾い物

ときどき、選択肢が一つ増える。点線の琥珀の縁と「拾い物」の札が付いているものがそれで、選んでも何も失わない。

- 決着のあと、見慣れない主役の札が一枚まぎれている。
- 古物商の棚に、半値の札が下がっている。
- 出来事に、妙な選択肢が一つ増えている。
- 食堂の店主が、負けのない賭けを持ちかけてくる。

## 抜けたあと

三つ目の区画の最後の相手と決着がつけば、抜けたことになる。そこで灯りを置くか、さらに下りるかを選ぶ。

下は、上の区画と同じ造りの、もっと古い階が続く。区画ごとに相手は手強くなり、秘密は漏れにくく、嘘の手がかりが混じる。抜けたあとは、地図の上の「その場で」からいつでも灯りを置ける。

点は、下りた深さ、持ち帰った記憶、成立した構成、見つけた隠し効果で決まる。

## 用語

| 語 | 意味 |
| --- | --- |
| 体力・精神 | どちらかが尽きると灯りが消える |
| 守り・構え | 次に受ける傷（体・心）を受け止める |
| 回数 | 札を使える残り。0 でも使えるが、効き目と代償が変わる |
| 硬度 | 総合の強さ。1〜10 |
| 見せ場 | その部屋で輝くタグ。相手も手強い |
| 掟 | 区画ごとの手番の変わり方 |
| 冠 | 区画を抜けるたびに、振る舞いから付く呼び名 |
